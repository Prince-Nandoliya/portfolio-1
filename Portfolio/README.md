# Prince Nandoliya - Modern React Developer Portfolio 🚀

A high-performance, futuristic, cyber-glassmorphism developer portfolio engineered with **React 19**, **Vite**, and **Tailwind CSS**.

![Preview](public/profile.png)

## ✨ Highlights & Features

- **Cyber Glassmorphism UI**: Built with deep slate and midnight indigo tones, custom glow keyframes, grid textures, and smooth glass panels.
- **Dynamic Typewriter Hero**: Showcases multiple developer titles (*Full Stack Developer, MERN Stack Specialist, Node.js Engineer, BCA Scholar*).
- **Interactive Avatar Frame**: Featuring Prince's official photo with floating tech badges (*React, Node, Mongo, JWT*).
- **Interactive Developer CLI Shell**: A built-in terminal (`prince@dev:~$`) supporting commands like `help`, `skills`, `projects`, `education`, `contact`, `resume`, `hire`, and `clear`.
- **Filtered Skills Ecosystem**: Categorized by *Frontend, Backend & APIs, Databases, Dev Tools, AI Augmented Workflows, and Core CS*.
- **Featured Projects Showcase**: Detailed modals with feature checklists, tech tags, and direct repository links (*JWT Auth, E-Commerce, React Showcase, TechWar 2026*).
- **GitHub Spotlight**: Displays real-time stats (42+ public repositories) and pinned GitHub projects.
- **Education & Industry Journey**: Interactive timeline for BCA at *Surendranagar University (2026-2029)* and *Red & White Multimedia Education (2025-Present)*.
- **Certifications Showcase**: Highlighting *Future Forward (Design + Development)* and *Tech War 2026*.
- **1-Click Contact & Copy**: Instant clipboard copy with feedback toasts for Email and Phone, plus an interactive contact form with confetti celebration.
- **Resume Downloader**: Instant download of the bundled `PrinceResume.pdf`.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVG Vectors
- **Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Fonts**: *Space Grotesk*, *Inter*, and *JetBrains Mono*

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Production Build
```bash
npm run build
```
Creates an optimized static bundle in the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```
Runs the preview server on [http://localhost:4173](http://localhost:4173).

---

## 🌐 Deployment

### Deploy to Netlify
1. Connect your GitHub repository `Prince-Nandoliya/<repo-name>` to [Netlify](https://app.netlify.com/).
2. Set build command: `npm run build`
3. Set publish directory: `dist`
4. Click **Deploy Site**!

### Deploy to Vercel
1. Import repository in [Vercel](https://vercel.com/).
2. Framework Preset will automatically detect **Vite**.
3. Click **Deploy**!
